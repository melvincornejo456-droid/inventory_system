Inventory & Sales Management System

A web-based Inventory and Sales Management System developed using PHP and MySQL. This application helps manage products, monitor stock levels, process sales transactions, and review sales records.

Installation

Install XAMPP.

Clone or download this repository.

Place the project folder inside htdocs.

Create a MySQL database named inventory_system.

Configure your local database connection in db.php.

Import your database schema or backup locally.

Start Apache and MySQL through XAMPP.

Open your browser and visit:

http://localhost/inventory_system/
